# ADR-0001：記錄架構決策

- 狀態：已採納
- 日期：2026-10-08

## 背景

這個專案會長期維護、只能利用零碎時間開發，同時也是作品集。
未來的自己、協作者與審閱者都需要知道事情「為什麼」是現在這樣，而不只是「是什麼」。

## 決策

每個重大決策都以 ADR 記錄在 `docs/adr/`，依序編號，包含「背景／決策／影響／考慮過的替代方案」四個段落。
ADR 一經採納即不再修改；決策改變時新增一份 ADR 取代舊的，並把舊 ADR 的狀態改為「已被 ADR-NNNN 取代」。

## 影響

- 決策可以像程式碼一樣在 PR 中審閱。
- 每次重大變更多一點撰寫成本。

## 考慮過的替代方案

- **Wiki 或聊天紀錄：** 會與程式碼脫節，也沒有經過審閱。
