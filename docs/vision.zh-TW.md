# 願景與範圍

[English](vision.md)

## 願景

讓家庭在一個私密的地方管理共同的日常系統：金錢、時間與雜務。
設計貼合這個家庭實際的運作方式，並且新增系統時不需要重做既有的部分。

## 使用者

| 使用者 | 現況 | 備註 |
|---|---|---|
| 兩位成人（夫妻） | 主要使用者 | 在 iPhone 與網頁上使用 |
| 小孩 | 未來 | 受限角色，長大後再加入 |
| Demo 訪客 | 未來 | 只能使用隔離的沙盒，絕不接觸正式環境（見 [ADR-0010](adr/0010-isolated-public-demo.zh-TW.md)） |

## 目標

1. 隨時看得到本月共同開支的總額，以及每位成人各付了多少。
2. 每位成人都能有一本私人的個人帳。
3. 新增模組（行事曆、採買清單⋯⋯）只需要新增一個套件，不需要修改平台。
4. 在家中運行是安全的，以開源形式公開也是安全的。
5. 運行成本趨近於零。

## 暫不處理

- 銀行或信用卡自動同步。
- 從其他 App 匯入歷史資料。過去的紀錄以手動輸入。
- 原生 iOS App。iPhone 使用 PWA。
- 與 iPhone 內建行事曆同步。之後可能提供唯讀的 ICS 訂閱。
- 任何形式公開正式環境。

## 路線圖

每個階段都先交付可用的成果，再進入下一階段。

| 階段 | 交付內容 |
|---|---|
| 0. 設計 | 本文件集 |
| 1. 平台骨架 | Monorepo、CI、登入、家庭、RBAC、稽核紀錄、自動產生的文件 |
| 2. 記帳 MVP | 共同帳本（觀察模式）與個人帳本，見 [finance.zh-TW.md](modules/finance.zh-TW.md) |
| 3. 家中部署 | NAS 上的 Docker Compose、Tailscale 存取、備份並實際演練還原 |
| 4. 本機 Demo | `docker compose up` 搭配虛構的示範資料，README 附截圖 |
| 之後 | 分攤與結算、收入、AI 建議分類、行事曆、採買清單、雲端沙盒 Demo |
